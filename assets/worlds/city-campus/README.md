# City/campus sample world

World format: Minecraft Java Edition 1.21.1.

1. Download or clone the repository with Git LFS enabled.
2. Extract CityCampus-world.zip into the Minecraft instance's saves directory.
3. Confirm the resulting layout is saves/CityCampus/level.dat.
4. Install the versions listed in the root README and mods/README.md.
5. Enable assets/resourcepacks/characters-v12-1.21.1.zip in Minecraft before reviewing the character models.

This is a sanitized share copy. Player data, advancement/statistics folders, session locks, instance configuration and local logs are not included.
