# 人物皮肤、模型与动作素材

## 推荐主线：按动作设计人物，而不是先换皮肤

保留七位角色身份与既有造型。先用陈师傅、A 验证一套共同标准，再推广；下列是制作提案，尚无新皮肤/模型成品。

| 角色 | 精细化重点 | 必须同时检查的动作 |
|---|---|---|
| 陈师傅 | 工衣领口、袖口、缝线、局部磨损，安全帽与头发分层；脸部疲惫用克制姿态表达 | 跑动推离、扶人、接听、坐起、收包，帽沿不切头/肩 |
| A | 衣服与发型轮廓、手机握持手，面部和手臂细节统一像素密度 | 持手机看向周然、停顿、拾外衣、坐姿；手机不能嵌在掌/袖中 |
| 周然 | 与 A 保留色彩与轮廓差异；寝室装束连续 | 收书入包、醒来落脚、站起、转身叫人 |
| 老人 | 衣褶、灰发、购物袋持点，避免夸张老态 | 失衡落地、疼痛停顿、借力起身；裤腿弯曲处不得露空 |
| 教师 | 领口、袖口与整洁轮廓；近景面部减少花纹干扰 | 自然听答、单次指示、转向、关投影 |
| 路人/工友 | 与陈区分衣服/头部轮廓，设备/工作装有一致位置 | 手机转向、停止录像、蹲拾、协助与疏导 |

现有包采用色板＋分部件方块，不是通用 skin.png。建议先保留 10/12 部件数量与尺寸，单独制作角色图集（先对照 128/256 图集方案，按画面距离决定，不把这些分辨率当作普通玩家皮肤格式）。同一关节前后截面纹理衔接，补闭合端面；中性姿态、肘/膝弯曲与抬臂分别核对 UV。表面加厚只用于衣领/袖口等有意义部位，不能用膨胀模型掩盖错误关节。

皮肤和动作共同交付：中性姿态、正侧背渲染、UV 图集、关节中心/旋转轴、可达手锚点、脚底面、道具附着点、支持动作清单、资源哈希。头部表情先沿用已存在嘴型，新增眨眼/眉形必须有实际绑定与回放验证。

## 如何适配成自然表演

1. 先确认目标角色中性姿态、骨长、肘膝轴和手脚锚点；不得对肢体非均匀拉伸以匹配动捕。
2. 将参考动作拆成意图、准备、主动作、承重/接触、缓冲、收尾；保留肩髋错相和先眼/头后身体的转向。
3. 动捕根位移统一单位，脚接触时锁地；角色到目标的路径另行约束，不能用移动根节点拖着踏步循环走。
4. 按当前游戏 tick 驱动确定性曲线；30fps 导出检查插值。动作交接写入口/出口状态，不让播放器循环重置手和道具。
5. 扶人/推离/落地为双人编舞：统一事件时间，接触时同一空间锚点，随后才承重或分离。皮肤库和物理 Mod 都无法代替此步骤。
6. 静止、走停转、持手机、扶起四项先过正常速度和关键帧审核，再扩展收包/外衣/醒来。只放大纹理而没有改善动作的方案不算成功。

## 历史文件元数据疑点

Fresh Moves 3.1 候选虽然出现在 API 的 1.21.1 筛选结果中，文件名与发布说明对适用版本的表述并不完全一致（发布说明写 1.20.2 及以下）。此候选暂降为“版本待核”，Windows 不直接启用；应按作者对应版本分支重新选文件并试拍。原查询及文件哈希保留用于追溯。
