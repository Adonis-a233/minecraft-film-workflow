# 试点：街头扶人 + 短步行/转身校准

选择原因：S02 70s 的多人扶人是已观察的可读性问题；共享街头事件有回放、8个镜头和跨幕消费者，最适合检验“修一个动作而不是重做全片”。本次仅交付设计和旧画面证据；尚未实机修复/试拍，不替换成片。

## 范围与入口

- 一个现有街道小区域，陈师傅/老人/工友三个既有模型；一个6秒动作校准段 + 一个10秒扶起段，共16秒表演素材。扶起段导出正面、侧面诊断、最终三分之二侧视三机位，复用同一表演母版。
- 基线A：现有rig/动作；候选B：仅改接近距离、接触锚点、关节变换/过渡。A/B先用相同无shader或同一固定shader配置；通过动作验收后再做光影与布景比较。
- P0入口：恢复 `visual-binding-v10.json`，绑定模型哈希；确认正版1.21.1/Fabric/Java21实例、Bridge、Carpet、ReplayMod；外部校园资源包、ffmpeg/ffprobe齐备；隔离世界复制而非原存档就地试验。
- `valid-support-rise.json` 是可复用的约束样例：陈 `(493.9,0,89.5), yaw=-50`；老 `(494.5,0,90), yaw=0`；工友 `(495.2,0,90.5), yaw=125`；区域 `(490,-1,86)` 至 `(499,8,95)`。**这只是fixture坐标，尚未证明当前世界此处安全**。现场测地面、路缘、体型和路径后确定初态/许可区域，不直接复制fixture中的world名开拍。

## A. 校准段 P-CAL，6秒/120ticks

目的：静止姿态、脚掌支撑、短步行、减速、转身和过渡是否自然。以陈师傅为先；通过后老人/工友分别复验比例，不能假定同一骨架参数通用。

| 时间/tick | 表演 | 验证 |
|---|---|---|
| 0–1s / 0–20 | 静止，视线停留，轻微呼吸，双足承重 | 肩肘/髋膝无缝隙，脚不悬空，无重复插值重启 |
| 1–3.5s / 20–70 | 沿已确认同层直线路径行走约1格 | 步幅跟实际位移，不固定时间摆腿；每脚落地与速度一致 |
| 3.5–4s / 70–80 | 减速、收步、重心稳住 | 不突停、不继续滑脚 |
| 4–5s / 80–100 | 视线先看目标，再转身约45度 | 脚掌有小步重定位，头/肩/胯错峰；不是原地整体刚性瞬转 |
| 5–6s / 100–120 | 稳定终态 | 终态可作为下一动作入口，呼吸不过度 |

路径起止、目标和相机在现场测量后填入镜头卡并冻结；当前不编造已验收坐标。现有 `walk_to`/`look_at` 可作A基线，先头后身与脚锁定作为B的实现需求，现有schema未承诺支持全部曲线。声音暂用脚步/衣物提示；应与落脚tick对齐。

## B. 扶起段 P-SUPPORT，10秒/200ticks

使用现有 support/rise 约束开始，不追加复杂掉板、手机、拾菜支线，完整保留“失衡/落地→扶持→借力起身→松手确认”因果。它是街头事件的独立表演试验，不是完整事故剧情替代；正式换入S02前还要与推人/落物/拾物段拼接验收。

| 时间/tick | 陈师傅、工友 | 老人 | 检查点 |
|---|---|---|---|
| 0–2s / 0–40 | 注意老人；动作准备，先确定支撑脚 | fall_down阶段，受惊/护腿 | CP1：落地姿态与地面，三人头肩净空 |
| 2–5s / 40–100 | support_actor伸手到指定上臂/背部锚点 | 保持低位、迟疑，准备借力 | CP2：先建立接触再承重，掌心不穿胸；双方头部保留空间 |
| 5–7.5s / 100–150 | 保持支撑，身体随老人重心移动 | rise_supported，逐步站稳 | CP3：脚滑/手漂移、肘长、相互穿插；起身不是整体上浮 |
| 7.5–8s / 150–160 | 继续支撑，确认站稳 | 稳住 | 避免站起瞬间手消失或悬空 |
| 8–10s / 160–200 | 缓慢收手，视线确认 | 回应与站立 | CP4：接触释放自然、终态与下一段一致 |

以上节点来自现有200tick fixture，表演细节需要候选动作实现和创作确认。A若无法精确表现，记录缺点而不删掉节点。检查点不通过时不开始下一独立录制段；同一次连续take内不人为暂停时钟，失败后回到段初态重录并检查各节点。

摄影：先复用旧 SH_aid 的最终构图作为A参照；B拟用中全景三分之二侧视、约45°FOV、稳定机位，手掌/双足与三个头部必须入画，避开前景路缘遮挡。另加正侧面和俯视诊断机位，不将诊断图当成正片。具体XYZ/角度从现场测量回填；只有完成机位卡、起止tick映射和边界检查才可执行。转场用稳定终态硬切，试点不加花式转场。声音提示为跌落、衣物摩擦、呼吸/用力和一句询问，正式对白不在未授权情况下重写。

## C. 验证方法与通过门槛

1. 固定A输入，记录录制/导出/人工审阅耗时；关键接触窗每帧检查，其他部分正常速度看，不靠缩略图打分。
2. B只改动作/rig和必要站位。trace输出每tick根位置、部件变换、关节端点、接触误差、脚支撑状态；同时检查非预期部件/角色/方块相交。每个假设单独归因。
3. 建议试点初始量化阈值：非预期可见穿插为0；接触窗口掌心到目标误差≤0.03格；支撑脚平面漂移≤0.03格；关节端点误差≤0.01格。阈值需按模型尺寸/1080p实际可见性确认，非当前软件已有保证；数值过线也必须人工通过。
4. 正常速度审核不再出现“头肩挤成一团”、身体上浮、脚滑、机械同时转身；关键帧关节连接不露背景，服装/UV无破面；口型和拟音检查单列。
5. 同一输入重录/重导三次；根/关节误差落在约定容差，视觉一致。不要要求不同UUID/时间戳的整个mcpr二进制哈希相同；同一已冻结输出才做逐字节哈希核对。
6. 动作通过后，同回放/机位比较无shader、Complementary r5.2.2、MakeUp9.6；先只换光影，再只加局部背景细节。每项记录启动、回放seek、导出、内存、秒/帧、阴影/白帽/皮肤表现。选择效果达标且总工时较低的方案，未测试前不指定胜者。
7. 影响范围演练：改相机只产生该镜头重导；改字幕只重编章；改次级资源包哈希必须使相关渲染失效；改扶人动作只重录扶人段及状态耦合段，再列出所有消费者。新依赖机制未实现前人工核对清单，不假称现有总控已经能完成这四项。

成本指标不先许诺百分比：比较A/B人工分钟、失败take数、机器分钟、首次通过率。允许B首次制作更贵；只有后续一次局部修改明显少于整幕重录且未降低表演质量，才认定成本优化有效。

## D. 重拍、停止与推广

- 路径/碰撞失败：恢复段初态，改走位或接触pose，重录该10秒段及其三机位；其他无关章不动。
- 机位遮挡：同一合格母版改机位重导，不重演。
- UV/部件比例：模型修复后重新校准；影响该角色接触的所有动作复验，禁止只挑不露馅的角度。
- 模组崩溃/回放丢部件：候选环境不入生产，恢复锁定基线；保留简化复现与日志。
- 找不到绑定/原始动作源：停止声称可复刻旧表演，登记缺项；可另行制作新rig但需单独估算与验收，不冒用旧版本名。

交付物：A/B带声音视频、关键帧、碰撞/关节诊断、输入清单与哈希、性能/工时记录、逐镜头审核单、变更影响报告。试点全部通过后先扩展共享事件其余段，再复核S01/S02/S03/S05/S06中的引用，之后进入S04坐姿和S07收包，最后是全片。未通过前不批量重拍68镜。
