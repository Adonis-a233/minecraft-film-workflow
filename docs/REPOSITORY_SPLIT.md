# 分支约定

main保存通用工作流代码、合同、测试、最小示例及开发文档。

codex/film-kanjianduoshao-assets保存本片规划、素材清单、地图、角色、影片与执行交接。Windows制片继续使用影片分支，并保留自身未提交的适配器和实例文件。不要将main的资产删除提交合并进当前制作工作区。

通用修复优先在main开发，再选择性带入影片分支。不得将影片分支整体合回main。历史未重写、服务器LFS对象未删除；仓库历史仍含旧影片资产。新用户可浅克隆main避免拉取历史大对象。

兼容分部件模型的旧换角适配器作为代码保留，限制见RECAST.md。main不承诺任意皮肤或任意影片一键录制，实机世界、动作与拍摄后端需要明确配置。
