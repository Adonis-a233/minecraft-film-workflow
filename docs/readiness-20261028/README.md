## 今天冻结的制作决策

1. 剧情按用户正式剧本；七幕顺序、共享街头事件、匿名加工者与结尾余波不再改。510秒是当前预算，如自然动作确实放不下则显式调整，不靠删必要动作硬凑。
2. 明日主线以原 Windows 世界、七角色和 ReplayMod 为基线。暂不整体换图、换CPM骨架或装物理Mod，不把今天下载的候选全部复制进去。先恢复并验证原实例，减少环境变量。
3. 优化顺序：**动作接触与关节→必要背景补景→光影对照→精细纹理推广**。原绑定不可靠时，先修绑定，增加纹理细节无法补救。
4. 场景准备可按 E/C/D/W 分组；镜头及依赖审核仍按卡片进行。共享事件首先冻结，手机/监控来自同一母版；新版本不能复用包含旧角色/旧表演的固定片段。
5. 每次运行唯一 run/take/output；原存档与原回放不覆盖。超时结果未知先查询状态，禁止盲目重发录制/生成请求。已有项目锁和恢复机制继续复用。
