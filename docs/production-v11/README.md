## 本稿的创作决定

全片围绕一个动作在不同信息范围中被解释的变化。第一次出现手机片段时不替观众判案；第五幕用同一次表演的连续广角补足危险来源；第六幕让人物说出自己缺的证据；第七幕保留更正后的生活阻力。陈师傅不演成摆英雄姿态的人，老人不演成笑料，A不演成蓄意造假的反派，周然也不是从头正确的代言人。

对白时码暂沿用原ASS；它们是可复核的剪辑锚点，不是新声音已完成。身体先形成表达意图，再说话；停顿、听者反应和手中事情继续变化。先用原声音做排练，再按正式表演调整分轨；任何对白重录或时长变动都需重新登记，不能让旧整片音轨覆盖新动作。

主要制作顺序：共享事件关键接触试点→冻结共同事件→S01/S06同课堂成组拍摄→S03/S05/S07宿舍成组拍摄→S04/S07工地休息室→图文剪辑→按剧情顺序逐幕验收→全片正常速度带声音终审。成组拍摄节省换场，验收仍按幕、镜头和独立动作段。

开拍前还缺：姿态绑定文件、当前rig与动作参数标定、世界局部锚点、最终机位坐标、校园包及拍摄环境锁、分轨声音。缺项不妨碍完成导演规划，但阻止把规划标成ready_to_shoot。工作区已有其他代码改动，本次只新增本目录，不覆盖它们。
