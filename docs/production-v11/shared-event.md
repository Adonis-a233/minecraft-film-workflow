# E 街头事件唯一母版

以用户剧本第二、第五场为依据。本节秒数与位置均为[导/测]的重新编排，不声称等于旧回放tick。所有手机、监控、课堂回看均引用同一经审核表演；不能为手机版把陈演得凶、为监控版另演救援。

## 空间与初态

局部原点为危险落点E.H=(0,0,0)，围挡位于z=-1附近；通行线沿z方向。老人从E.O0=(0,0,-2)走向E.H，推离后到安全侧E.OS=(0,0,1.5)。陈E.C0=(-1.5,0,-0.5)，视线起初看工作区，不与老人交谈；工友从围挡出口E.G=(2,0,-1.5)出来，避免经过落物区。路人E.F=(2.5,0,2)，先面向路线方向，再转向老人，完成录制后手机收起。

板材初始中心候选(0,3,0)，落点E.H，规格与旋转轴按实际道具测量。安全侧、通行线、板材边界必须做扫掠碰撞，老人完全离开危险体积后才允许板材落地；影子、反射和声音方位也要保持同一事实。初始坐标不能直接作为实机安全证明。

## 事件时间 E 秒（0–32.5；650 ticks）

| E时间 | 人物、道具动作与状态 | 声音/检查点 |
|---|---|---|
| 0–4.5 | 老人沿E.O0→E.H慢行；陈在E.C0工作；路人录前往店里的路线，镜头不含板材来源；两人没有交谈 | 路人原台词“我到这了。那个门封了，你绕到——”。老人走路不是机械摆腿，袋随步幅轻摆 |
| 4.5–5.5 | 上方板松动；陈先抬头发现，再迈步接近老人；旁人短促示警，路人转手机 | 示警声音不是新解释性台词。手机转到事件时不能提前拍到上方松板 |
| 5.5–6.2 | 陈从E.C0向老人左后侧赶到；支撑脚落地，手掌触上臂/躯干侧，再施推力向+Z安全侧 | 明确接触先于老人位移；推人不能隔空，也不能掐脖子 |
| 6.2–7.5 | 老人移向E.OS，失衡跌坐，袋释放，物品散落；陈收推力并转头查看落点 | 推动与失衡有重量，脚/膝/手触地逐项看。物品离袋后不再随前臂一起移动 |
| 7.5–8.3 | 板落E.H，位于老人此前位置；路人因闷响惊动，手机小幅晃动，始终未拍到落点 | 同一闷响保留于原手机音轨；不加蓄意剪切来“藏”声源 |
| 8.3–10 | 陈看一眼落板再回老人；路人片段继续，手机画面能看见跌坐后状态，仍不见板 | CP1：全景可判读避险因果；手机只有推人/跌坐事实，无原因结论 |
| 10–13.5 | 陈靠近老人；工友由E.G绕安全路线出现。路人质问，陈关注伤情 | “哎，你怎么推人啊？”；陈不是先对质或回骂 |
| 13.5–20 | 路人停录；陈脚站稳、手先搭稳再扶；老人说腿疼后停一下再借力，工友接另一侧；老人保持背对落点 | “先起来，这儿不能待”“我腿……等一下”。CP2：三人头部不重叠，手锚点可辨；停止录制要发生在路人开始帮忙前 |
| 20–23.5 | 工友提醒离远、扶老人向安全出口E.OUT=(2,0,3.5)走，先转脚再转身；陈松手确认 | “都离远点！”；CP3：换支撑者不失重，老人不突然转头看到落点 |
| 23.5–27.5 | 路人收好手机后屈膝拾物，一件件移交袋；陈只协助近侧物，不两人挤同一点 | 接触/抓取/释放唯一，物品不瞬移；CP4检查肩肘连接和地面余物 |
| 27.5–32.5 | 工友与老人继续离场，老人回问出什么事（剧本未给原句，只用含混问询声或待配原句）；陈留围挡旁看现场，路人完成拾物 | CP5：陈不跟老人一起离场；不添加老人当场讲明板材救援的台词 |

如完整起身/拾物无法在上述时间自然完成，先调段长与母版时基，更新消费者；不加速肢体、不删掉过渡。保持S02总预算45s的前提下可减少发布卡冗余停留；若仍不够，登记全片时长变更。

## 视角与引用

- E.ROUTE：路人手机高度约1.5，先指向店铺路径；E=4.5开始转向。真实手机位姿取路人rig锚点，不等于一台穿过人物头部的外部镜头。
- E.PHONE：从路人锚点看老人胸部/陈伸手，竖幅视觉区；母片16:9内保留竖幅和黑边，不把挤窄画幅当降画质。固定同一次转动/惊动曲线，所有复用镜完全一致。
- E.AID：中全景候选(3.2,1.35,4.5)看(0,0.9,1.4)，FOV48；最终至少看清老人脚/膝支撑、两只扶持手与三人脸。观察机位不偷看板材来源，S02仍保留因果未知。
- E.PICK：候选(3,2.2,4)看(1,0.4,1.7)，FOV50；路人、物品与袋分层，陈不靠路人肩膀站。

## 剧情/物理验收

手机片段使观众能说“看见推倒”，不能单靠表演额外暗示“看见争吵”；监控让观众能说“板材落在原位置，推离避险”，不能凭标题替画面下结论。扶人不遮动作，拾物不露肩部缝隙；事件里的呼喊、闷响和拍摄停止点可在唯一时间线上定位。修改任一动作或声音锚点，检查S01/02/03/05/06全部引用并撤销相关审核，不能只改其中一版。
