# S06 下节课 区分看见和解释

净时长 **100秒**；全片 **05:30–07:10**；场景：C 教室 + E引用 + UI。状态：导演规划，待现场标定。

剧本依据：用户剧本 [P091–P114](../script-extract.md)。对白以该原文为准，旧ASS仅提供临时时码。

## 戏剧与表演

把观众已看到的条件变成可辨认的认识过程：事实、解释、补充证据、修正。教师引导，A自己承认来源。

教师耐心追问；学生由确信到迟疑；周然承认自己也参与猜测，望向A；A从回避到说出“标题写的”。

## 入口状态与连续性锁

仍是C同一教室与轴线，A/周然席位不变；匿名学生的台词不能全部指定周然。原手机与监控顺序不变。结尾A看的评论必须等于S03已发送内容；铃响后教师关投影。

所有局部锚点、机位预设、动作模块及通用验收G见[制作共同约定](../production-bible.md)。下列秒数均为本幕局部秒，E时间另指共享事件秒。镜头按上镜终态衔接，不能每镜重置站姿。

## 拍摄顺序与审核点

课堂对白按提问/回答/沉默分段录，长句在一个表演段中完成；不用每句都重建教室。背景学生最多少量不同听姿，不能齐刷刷点头。教师手势、学生反应和投影开关需单独检查。

每个独立动作段先排练/导出/审看，合格才执行依赖段；纯UI镜头只走图文剪辑审核。超过10秒镜头按明确动作节点检查，连续事件不以藏切规避失败。
