# S04 陈师傅 画面之外的代价

> 2026-10-29 时基修订 E104.5：用户允许延长事件；本幕时码以 planning-index.json 为准。旧对白ASS只作声音素材索引，禁止整条旧音轨直接平移覆盖新表演。所有既有引用审核待重新进行。

净时长 **80秒**；全片 **04:07–05:27**；场景：W 工地休息室 + UI。状态：导演规划，待现场标定。

剧本依据：用户剧本 [P049–P073](../script-extract.md)。对白以该原文为准，旧ASS仅提供临时时码。

## 戏剧与表演

把传播后果落在工作、家庭和无法得到答案的具体处境上；陈不是被抽象议论的人。

接陌生电话时困惑，看到工牌扩散后焦虑，被要求休息后想争辩，给妻子回电时疲惫，最终对明天的安排不确定。

## 入口状态与连续性锁

陈在W.C坐，起始手机可拿到；工友先在门外，14.5s前进入W.S，之后始终在旁。陈自己的电话与工友展示的手机是两个独立道具；负责人、妻子、陌生人只用电话声，不添加新模型。

所有局部锚点、机位预设、动作模块及通用验收G见[制作共同约定](../production-bible.md)。下列秒数均为本幕局部秒，E时间另指共享事件秒。镜头按上镜终态衔接，不能每镜重置站姿。

## 拍摄顺序与审核点

同一布景锁定两个手机/桌/椅锚点；先验证坐姿接听、看工友屏幕和放手机。电话段按情绪节点分录，保留原对白；72–80s放桌、提问、无答、再响铃必须一段连贯验收。

每个独立动作段先排练/导出/审看，合格才执行依赖段；纯UI镜头只走图文剪辑审核。超过10秒镜头按明确动作节点检查，连续事件不以藏切规避失败。
