# S01 课堂 别只记结论

净时长 **55秒**；全片 **00:00–00:55**；场景：C 教室 + E.PHONE。状态：导演规划，待现场标定。

剧本依据：用户剧本 [P003–P016](../script-extract.md)。对白以该原文为准，旧ASS仅提供临时时码。

## 戏剧与表演

建立讨论的出发点和A的先入判断，随后把抽象的“反转新闻”变成将影响他们的具体事件。

教师从布置任务到提醒方法；周然从记事到关注消息；A从散漫、轻率到被事件吸引。

## 入口状态与连续性锁

A在C.A、周然在C.Z坐，教师在C.T。日历手机属于周然；收包也是周然。A凑看发生在收到视频之后；书、手机、书包各登记握持与桌面位置。

所有局部锚点、机位预设、动作模块及通用验收G见[制作共同约定](../production-bible.md)。下列秒数均为本幕局部秒，E时间另指共享事件秒。镜头按上镜终态衔接，不能每镜重置站姿。

## 拍摄顺序与审核点

先拍日历/收回与收包动作样板，再录教师和学生对白段；C.W建立空间后复用两个对话机位。39–47s收包分准备、放书、收手三个检查点；新录该段替代旧固定视频。

每个独立动作段先排练/导出/审看，合格才执行依赖段；纯UI镜头只走图文剪辑审核。超过10秒镜头按明确动作节点检查，连续事件不以藏切规避失败。
