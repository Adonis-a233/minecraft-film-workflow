# S03 宿舍 解释变成事实

净时长 **75秒**；全片 **01:40–02:55**；场景：D 宿舍 + UI + E.PHONE。状态：导演规划，待现场标定。

剧本依据：用户剧本 [P030–P048](../script-extract.md)。对白以该原文为准，旧ASS仅提供临时时码。

## 戏剧与表演

呈现观察如何经过评论、标题和工具加工变成确定说法；A不是自动剪辑操作者，但要承担自己添加判断并转发的行为。

A从困惑到确信，周然从猜测到附和；结尾A把质疑当成无须回答的问题，发完后轻松去吃饭。

## 入口状态与连续性锁

A在D.A、周然D.Z；手机先由A持。工具段操作者不露脸、不具名，不与A按键动作匹配剪辑。外套在D.COAT，拿衣由A完成；周然先向门口准备走。

所有局部锚点、机位预设、动作模块及通用验收G见[制作共同约定](../production-bible.md)。下列秒数均为本幕局部秒，E时间另指共享事件秒。镜头按上镜终态衔接，不能每镜重置站姿。

## 拍摄顺序与审核点

先拍持手机与听者反应，图文按原信息链制作；工具加工只用后期图文和已审核的E.PHONE衍生。55–57收手机、72–75取衣须建立新动作与母版，不能继续引用缺版本固定视频。

每个独立动作段先排练/导出/审看，合格才执行依赖段；纯UI镜头只走图文剪辑审核。超过10秒镜头按明确动作节点检查，连续事件不以藏切规避失败。
