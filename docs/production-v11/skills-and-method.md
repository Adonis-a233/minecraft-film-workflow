# 实际参考的专业 skills 与方法边界

已检索当前本地技能及插件目录。本地没有专门的电影摄影/角色表演技能；插件检索返回视频生成服务，不适合替代本项目的游戏内实拍。因此参考以下公开社区SKILL.md；没有安装它们、执行第三方脚本、调用视频生成服务或更换拍摄链路。它们是社区方法总结，不等同于经过本项目实机认证的工具。

| 已阅读来源 | 本稿采用的范围 | 本稿中的落点 |
|---|---|---|
| [cinematography · everything-ai-filmmaking](https://github.com/MRCalderon3D/everything-ai-filmmaking/blob/main/.claude/skills/cinematography/SKILL.md) | 先定义镜头要表达的戏，再决定景别、视点和运镜；保持反打一致 | S01建立教室关系；S04压缩陈师傅独处空间；S06在A承认信息来源时才靠近 |
| [create-storyboard](https://github.com/TateZhouSiu/create-storyboard-skill/blob/main/skills/create-storyboard/SKILL.md) 及 [workflow](https://github.com/TateZhouSiu/create-storyboard-skill/blob/main/skills/create-storyboard/references/storyboard_workflow.md) | 每镜写清起止状态与前后镜交接，提前规划轴线、视线和道具连续性 | 每幕表中的“剪辑交接”；共享手机/监控引用；S03取衣与离场动作完整保留 |
| [animatorsSurvivalKit · custom_skills](https://github.com/sumyunq/custom_skills/blob/master/skills/animatorsSurvivalKit/SKILL.md) | 先做关键姿态和接触，区分准备、主要动作及余势；用正常速度与静音回看检查表演 | 扶人先握稳再起身；走路与脚掌承重匹配；收包分取书、放入、释放、收手；听者的动作反应 |

本稿不照搬skills的全部要求：分镜技能中的Seedance时长上限、提示词、图像生成交付不适用于本次Minecraft文字规划；摄影技能的真实毫米焦距不直接等同于Minecraft FOV。本文用游戏FOV候选与景别目标，现场以投影画面确认。

动画技能中的“所有轨迹必须成弧”“恒速一定错误”、机械地按体重分配帧数，以及固定频率眨眼/固定比例夸张，不能当成物理或表演定律。本片保留平稳行走和真实停顿；不为满足公式增加动作。分部件硬模型保持骨长与外形，用屈膝、重心和支撑表现重量，不默认拉伸骨骼。现有嘴型只有0/1/2三帧，不声称已有四至六口型、独立眼球/眉毛或手指绑定；新增表情须新增资产并验收。

专业方法为规划提供检查框架，具体剧情、台词、秒数、走位及资源选择均根据本项目材料设计。文件链接记录本次所读版本的入口；若未来采用为可执行技能，需另外锁定提交、许可与依赖。
