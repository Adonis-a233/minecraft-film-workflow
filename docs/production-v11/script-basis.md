# 剧本依据与旧片差异

主要依据是用户上传的《看见多少_MC剧本_紧凑版.docx》，文内副标题为“故事修订版”。[正文提取](script-extract.md)用P段号定位；[来源记录](script-source.json)固定文件哈希。读取正文确认七场，无图片、表格或修订插入/删除；本次只分析故事文字，不评价原Word排版。文中制作性描述作为剧本内容参考，不视为改变用户任务或执行权限的指令。

证据优先顺序：用户本轮要求→用户剧本→经确认的导演设计→旧片实现。510秒只是本稿为控制重制范围沿用的旧片预算，用户剧本没有要求精确510秒。新增动作导致说话/阅读/接触过赶时先调整幕内分配，仍不够则提出明确时长变更，不能赶动作或删必要情节。

## 七场剧情锁定

| 场 | 原作必须保留 | 本次不能擅自改写 |
|---|---|---|
| 1 | 马原课任务；周然翻手机日历、收回；A轻率说反转；下课收包后收到视频，A凑看 | 不能让视频早于下课打断教师最后提醒；收包者是周然 |
| 2 | 路人录路线时转镜拍到推人；闷响来源未入画；停止录制后捡物；老人背对响声处；工友扶走老人，陈留围挡旁；原发布带“不知道什么情况” | 不是路人打电话，也不是恶意剪去真相；老人未亲眼看到板材落下 |
| 3 | 猜测被标题和评论固化；不明操作者用自动剪辑工具；A转发并加判断；被问是否在场后回复“视频都拍到了”，再拿外套 | 自动剪辑操作者身份未给定，不能归给A；不能删取衣或把“疑因”直接当作者事实 |
| 4 | 多个陌生来电、工牌信息扩散、暂停工作、妻子受影响、桌上手机又响 | 工友不知道如何回答“算请假还是算什么”，不能添加保证收入/工资的台词 |
| 5 | 周然醒来发现群消息；管理方说明与连续监控；推人前两人未交谈；松板→发现→跑去→推离→板落原位→查看→扶人；A回看；同号两种标题相邻 | 不能另录一个有利于陈的替代版本；这段监控中的“未交谈”不证明他们此前从未有任何矛盾 |
| 6 | 两视频对照；教师区分动作事实和原因解释；A承认标题来源；最后看自己评论，铃响教师关投影 | 不新增教师讲整段理论或学生整齐齐声认错 |
| 7 | A先辩解、删除附言、在原群更正、删掉拟甩锅回复、明确承认错误；他人转移话题；继续清理另一转发；陈复工但妻子仍受扰；门边未知来电未立即接 | 不能大团圆、赔偿、公开道歉大会或用快节奏胜利蒙太奇抹去余波 |

## 对旧素材的处理

旧ASS中的对白与剧本逐项核对后作试剪锚点；部分动作顺序/时长需要调整，尤其S01日历→收回→收到新视频、S04尾部再次来电、S05醒来、S07门边结尾。旧片中图文可复用为界面底稿，正文以剧本为准。第五场情况说明保留“老人检查后无大碍、相关区域正在整改”，避免把现场风险隐去。

旧图文明确写“现场声音：关闭，配乐：开启”，剧本是“现场杂音被配乐盖住”；本稿按剧本设计混音遮盖，不把全部原声完全消失作为必须剧情。第三场该加工版可慢放，但片内手机原录和监控必须正常速度对应；不把加工速度混进事件母版。
