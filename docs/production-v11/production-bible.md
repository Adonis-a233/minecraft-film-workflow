# 全片制作共同约定

## 1. 人物与表演

| 角色/现有模型 | 本次表演设计[导] | 忌讳与能力限制 |
|---|---|---|
| A / classmate:a | S01身体放松、先轻下结论；S03视线被手机吸住，说法越来越确定；S05手停在屏幕上，先困惑再理解；S06承认时抬头但不慷慨陈词；S07输入辩解后停下、改写并发送 | 不用一串夸张摆手代替思考；不临时起新名字。头向/肩向表达视线，不能假定已有眼球绑定 |
| 周然 / classmate:zhou | 开始也是猜测者；提问时轻侧身等回应，发现监控后主动共享；S07“我不也信了”同时承认自身责任，给A行动空间 | 不演成全知老师，不点头循环 |
| 教师 / classmate:teacher | 平稳、耐心，提问后把目光交给学生；在关键区分处只做一次有指向的手势 | 不用固定抱书姿势贯穿所有台词；书若有则始终登记持有手和放置位置 |
| 陈师傅 / classmate:chen | 事件中先注意危险再迅速行动；扶人时关心承重。室内被电话打断，想解释却越来越疲惫；返工通知只稍松口气 | 不带愤怒推搡的预备表情，不英雄式慢动作；“救人”由因果画面成立 |
| 老人 / classmate:elder | 购物后正常行走；失衡时护住身体、腿部疼痛导致起身犹疑；站稳后先找支点 | 不夸大衰弱、摇晃或把跌倒喜剧化；不用整个身体悬浮表示起立 |
| 路人/拍摄者 / classmate:filmer | 先录路线/转手机，拍到局部而质问；之后停止拍摄，注意到需要帮助，参与拾物 | 说“不知道什么情况”保留；不新增蓄意剪掉救人证据的动机 |
| 工友 / classmate:safety | 先注意现场风险、协助老人，再疏导；室内给陈师傅实际关照而非训话 | 与陈不能同时完成一模一样的扶人动作 |
| 负责人/妻子/陌生人 | 先保留原对白为电话画外声 | 不为短段声音新增角色模型；来电身份由原字幕/声音滤波区分 |
| 课堂学生 | A/周然及少量无对白背景学生；学生/另一名学生沿用原声音角色标签 | 原字幕没有证明每句学生台词都来自周然；不能全部强行分配给他 |

## 2. 可标定的场景坐标与镜头预设

以下均为**设计用局部坐标，单位格，Y向上**；不是当前存档测量值。开拍前每场实测世界原点O和水平旋转R，写入location-lock；世界点=O+R×局部点。所有“坐姿根点”需按rig坐姿的脚底接触重新标定。表中角色静止除明确动作外不得自行移动；路径变化须更新所有关联镜头。

### C 教室（S01/S06同场同轴）

- 黑板中心C.B=(0,1.6,-4)，教师C.T=(0,0,-2.8)，面向+Z（yaw0）。A席C.A=(-0.9,0,0)，周然席C.Z=(0.9,0,0)，面向-Z（yaw180）；桌面候选高0.8，椅高按腿长实测。走道C.P=(2.8,0,0)→C.D=(2.8,0,3)。禁止演员靠身体穿过桌子离席。
- 预设C.W：相机(3.5,2,4.8)，看(0,1,-1)，FOV60，中远景建立人物；C.TM：(1.8,1.5,0.5)看教师脸，FOV42；C.PAIR：(0,1.1,-2.2)看两人上身，FOV48；C.A/C.Z分别(0.6,1.1,-1.8)/(-0.6,1.1,-1.8)看对应学生脸，FOV38；C.PROP：(0.2,1.25,-0.9)看桌面，FOV38。
- 这些坐标是取景搜索起点；两人对话轴和师生轴不同。先用C.W/C.PAIR中性全景交代轴线，再进入相应反打；同轴内不随意越线。C.A/C.Z需实机核对屏幕视线方向，不能凭坐标标合格。
- 左侧窗为主光，暖顶灯补光，脸部不依赖极亮顶灯照平。前景少量座椅，中景表演，后景黑板和学生，保持走道通畅。

### D 宿舍（S03/S05/S07同场）

- A根点D.A=(-0.7,0,0)，周然D.Z=(0.8,0,0.4)；两人先面向+Z，周然再看A手机。桌D.TABLE=(0,0.8,-1.2)；外衣D.COAT=(-1,0.85,-1.2)；门D.DOOR=(2.6,0,2)；床边D.BED=(1.8,0,-1.8)，醒来段从床面姿态到床边脚落地再站起，床高/起身轨迹待标定。衣服取放点须满足当前右手可达域，必要时调整A到D.PICK=(-0.8,0,-0.65)，不伸长手臂。
- D.W：(3,1.5,3.8)看(0,1,0)，FOV55；D.TWO：(0,1.45,3)看(0,1.2,0)，FOV45；D.A：(0.4,1.45,2.2)看A，FOV35；D.Z：(-0.3,1.45,2.3)看周然，FOV35；D.HAND：(-0.2,1.5,0.8)看手机/操作手，FOV35；D.COAT：(-1.7,1.3,0.5)看桌上衣服，FOV42。
- 成对镜头在A—周然轴的同一侧；离开前先回D.W建立门方向。机位不得穿家具，持手机的手/手机朝向固定。普通64×64皮肤不可替代这些分部件模型。
- 用床铺/书本/水杯各一组构成生活背景，角色脸后不放抢眼灯；保留原空间主要轮廓，避免全面换图。

### W 工地休息室（S04/S07同场）

- 陈W.C=(0,0,0)，工友W.S=(1.6,0,0.5)，前者坐姿/后者站姿；桌W.TABLE=(0,0.8,0.75)，袋W.BAG=(0.3,0.8,0.65)，手机W.PHONE=(-0.25,0.825,0.65)；站起/收包根点W.STAND=(0,0,0)，出口W.EXIT=(-2.5,0,-1)。实际桌高、椅高、可达点须校准。
- W.W：(3.4,1.6,3.5)看(0.5,1,0.3)，FOV55；W.C：(1,1.1,2.4)看陈坐姿脸，FOV38；W.S：(-0.8,1.5,2.4)看工友，FOV42；W.PHONE：(0,1.3,1.5)看手机，FOV35；W.PACK：(-1.6,1.45,1.8)看陈手/袋/躯干，FOV45；W.DOOR：(-0.8,1.45,-2.6)看W.EXIT处陈的脸与持手机手，FOV40，需确认摄影机在墙体可通行侧。
- 桌沿不能遮住动作目标；反打匹配视线高度，站/坐高度差服务人物关系，不用夸张俯拍羞辱陈。背景放工具、水壶、工衣和窗口三层，保留被打断工作的痕迹。

### E 街头 / UI 图文

E见[共享事件](shared-event.md)。UI为后期图文，零游戏坐标/角色动作；保留原信息顺序，用可读字级和最短必要高亮，不重新演一套手机操作。图文时长内允许短暂切回人物反应，但文字可读时间不得被压缩掉。

相机朝向用position→look_target计算yaw/pitch，roll默认0；FOV是候选设置，不是现实镜头毫米数。开拍锁需把预设解析成数值相机关键帧、截图和已验证安全路径，不准执行Agent自行选择“差不多的机位”。轻推镜仅在卡片明确标注时发生，默认固定；屏幕插入不加炫技运镜。

## 3. 动作模块与能力边界

| 模块 | 表演/接触要求 | 对应已有能力与待实现 |
|---|---|---|
| ACT-IDLE | 有呼吸/重心但能安静听；视线在思想节点变化 | idle/pose可复用；轻微呼吸、独立视线需曲线支持 |
| ACT-WALK-TURN | 起步蓄力→加速→足锁定换步→减速→先头后躯干转向→收步 | walk_to/look_at可作基线，路程步态和分部位转身要适配；不让普通look_at冒充完整转身 |
| ACT-PHONE | 接通知→看→读→选择→放回；手中手机状态连贯 | phone/phone_call/phone_stop/phone_putaway系列已有；手指按键和新增表情尚无保证，用手腕微动/图文操作反馈表达 |
| ACT-PACK | 视线定位书→打开袋口→握书→放入→释放→收手→确认 | pack_bag_sit/stand与IK可复用；样板动作有角色/时长限制。S01包是周然桌前，先按旧画面核角色绑定，不擅改成A |
| ACT-COAT | 手机妥善处理→接近衣服→抓领→抬离桌面→衣摆跟随→持衣出门 | pickup_coat/hold_coat已有且限A；保留手机手状态，不自动生成换手 |
| ACT-PUSH/FALL | 发现危险→赶上→手掌接触→短促推离→失衡护体→受控落地 | push_actor/recoil_to/fall_down可复用；相互关系与跌落/落物窗口需联调 |
| ACT-SUPPORT | 接近→脚站稳→手触上臂/背→承重→老人借力→松手 | support_actor/rise_supported；手锚点、头肩净空、膝脚支撑必须实测 |
| ACT-PICKUP | 看清目标→屈膝→手触物→抓取→起身/转袋→放入 | pickup_groceries、GroundedStrideRig等；每件物有唯一所有者，原道具不双显/跳变 |

硬部件不非均匀缩放遮关节；姿态检查肩肘腕、髋膝踝连接，正侧背三个方向。0/1/2嘴型根据音节开合节奏驱动，不能逐字自动随机换嘴；没绑定的眨眼/眉毛不作为当前可执行要求。既有代码有硬约束时，编译器应报unsupported并安排动作适配，不能静默删动作。

## 4. 资源包、版本与声音

- MAP-CITY：现有CityCampus世界副本，按C/D/W/E区域快照登记；外部校园资源包哈希按原项目锁定，缺失则blocked。
- RIG-CAST：现有v8/v11/v12作为参考，不混用不同版本的身体部件。新拍摄优先统一一套经四动作校准通过的兼容角色包，命名RIG-V11-CANDIDATE；未生成时版本/哈希为null。不得声称现在已能统一用v12重拍全部旧动作。
- ENV-BASE：Java21、MC1.21.1、Fabric及项目锁定Bridge/Carpet/ReplayMod。SHADER-CANDIDATE优先Complementary r5.2.2；Iris/Sodium组合和配置经实机试拍后锁定。此前对照无shader仅用于诊断，不自动用于正式成片。
- 所有角色/地图授权沿用ASSET-CREDITS的非商业样例边界；新声音/音乐/字体逐条登记。无授权音乐不进入母版。
- 台词原文及时码见script-basis。声音分DX对白、FOLEY动作、AMB环境、MUSIC配乐；场内对白留真实停顿。S03视频加工界面才出现关闭现场声/开启配乐的故事行为；不能因此让全片把危险声证据删掉。
- 推荐本片原创配乐少用，S02不铺“恶人”音乐，S05不铺“英雄反转”胜利音乐；S07未知来电用普通铃声，留余味而非恐怖音效。这些是[导]，不是原声审核结论。

## 5. 每镜通用执行、审核与重拍规则

每幕镜头表必须连同本文件及场景预设读取。每行列出的角色继承场景起点/姿态，动作描述中明确移动才改变位置；连续场内动作继承上镜终态，独立重录从该状态快照恢复。UI镜头期间演员并未自动回默认姿态，回切要继承前一可见镜状态。

每镜流程：校验资源/位置/能力→恢复入口快照→预滚1s→动作段排练→导出诊断与正片视角→机器检查→人工正常速度/关键帧审看→记录签核→继续依赖镜头。镜头净时长不包括前后0.5–1s剪辑余量。超过10秒的镜头内按表演节点设审核点；有连续物理接触时不得为缩短段而丢失状态。

通用验收G：剧情目的看得懂；字幕时序及声画同步；身份/道具/朝向/轴线连续；无可见非预期穿插或关节裂口；脚掌承重、手掌接触成立；镜头机位无穿墙；输出正确但未人工审核时仍needs_review。截图不能代替正常速度审核。

重拍编码：**R-A**=动作/rig问题，重录该段与其状态依赖；**R-C**=只有构图/机位问题，从合格母版重导该镜；**R-E**=图文/声音/剪辑问题，仅重编相应章和成片；**R-S**=共享事件变化，检查全部引用。R-A不等于整幕重录，R-S也不等于整片所有镜头重拍。

从本规划到执行：冻结镜头卡→实测局部到世界变换/机位与角色引用→通过actor-plan白名单和动作约束→拍摄新回放/trace→生成film-shots规格及输出哈希→生成film-chapter/film-plan→按当前审核机制执行。导演规划JSON不伪装可执行合同，不伪造accepted_spec_digest或审核结果。
